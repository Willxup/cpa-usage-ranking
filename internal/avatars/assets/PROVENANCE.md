# Initial avatar asset provenance

The project owner approved reusing the existing 66 avatars from
`keeper-ranking-center`, preserving IDs 1–66 and selecting 001 as the default.
Files were copied byte-for-byte from that project's `web/avatar-sources/`:
`001.webp`–`066.webp` (128×128 WebP), now under `images/`.

`SOURCE.original.md` preserves the original
`assets/avatar-candidates/README.md` source record verbatim. Its relative links,
sprite instructions and frontend version references describe the **old**
project, not this distribution. The record identifies eight original candidate
sheets, six retained visual directions, and separately generated GPT Image 2
additions 055–066. No other generator attribution or asset license was supplied;
this distribution does not invent MIT, CC0 or other stock-image permissions.
Owner approval is not a claim about third-party license terms.

Only the approved WebP files and the catalog are embedded/served. No source
sheets, crops, old sprite, business logic or UI code were imported. Future
additions keep existing ID meanings; 66 is the initial count, not a limit.
